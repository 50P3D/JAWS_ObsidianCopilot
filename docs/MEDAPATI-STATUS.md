#### What Works:
- The command `NoteCheck: Fact-check selection` can be triggered from the Obsidian command palette.
- Grabs selected text and parent note title.
- Opens the results panel in the right sidebar.
- Renders full Claim Cards with colored verdict pills (`Supported` = green, `Refuted` = red, `Not Enough Info` = amber), collapsible evidence quotes, pinned Wikipedia revision URLs (`oldid`), and source reliability trust badges (`High`, `Medium`, `Low`) with reasons.
- Displays prominent suggested fixes when a claim is refuted.

## 3. How to Build and Test

### 1. Install Dependencies
```bash
npm install
```

### 2. Build the Obsidian Plugin
```bash
npm run build:plugin
```
Output files will be generated in `dist/plugin/`:
- `dist/plugin/main.js`
- `dist/plugin/manifest.json`
- `dist/plugin/styles.css`

To test inside Obsidian:
1. Copy `dist/plugin/*` into `<your-obsidian-vault>/.obsidian/plugins/notecheck/`.
2. Enable **NoteCheck** in Obsidian Community Plugins.
3. Highlight a sentence and run `NoteCheck: Fact-check selection`.

### 3. Run and Test the MCP Server
```bash
npm run mcp
```
Or test interactively using the MCP Inspector:
```bash
npx @modelcontextprotocol/inspector npx tsx src/mcp/index.ts
```
